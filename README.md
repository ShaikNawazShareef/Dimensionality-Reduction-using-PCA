# Dimensionality Reduction Using PCA

## 📌 Project Overview
This project demonstrates **Dimensionality Reduction using Principal Component Analysis (PCA)**, a popular unsupervised machine learning technique used to reduce the number of features in a dataset while preserving as much important information as possible.

PCA transforms high-dimensional data into a lower-dimensional representation, making data easier to visualize, analyze, and process.

## 🎯 Objectives
- Understand the concept of dimensionality reduction.
- Implement Principal Component Analysis (PCA).
- Reduce the number of features in a dataset.
- Preserve maximum variance using principal components.
- Visualize data before and after dimensionality reduction.
